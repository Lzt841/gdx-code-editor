# 编辑器实现检查与改进路线

检查日期：2026-11-22。检查基线：`v1.3.0`（`8ccd3a4`）。

本轮重点检查内容修改、输入过滤、搜索替换、撤销、代码片段、格式化、诊断修复和扩展命令。这里记录的是代码中可确认的
行为与限制，不代表已经完成所有渲染、手势和平台输入路径的审查。

## 本轮处理

| 问题 | 原有行为 | 本轮结果 |
| --- | --- | --- |
| 正则替换与输入过滤顺序错误 | 先过滤 `$1` 等模板，再展开捕获组；数字过滤器会把 `$1` 变成 `1` | 先展开每个匹配的替换文本，再对实际插入的字符过滤一次 |
| 相同内容替换污染历史 | 普通范围替换、批量替换和搜索替换仍执行删除及插入，改变版本、清空重做并触发内容事件 | 跳过最终文本相同的替换；全部无变化时保留光标、选区、折叠和历史 |
| 过滤回调后的状态未统一检查 | 普通替换可以在过滤器修改文档或切换只读状态后继续使用旧坐标 | 过滤结束后重新确认文档版本和编辑状态；拒绝外层过期操作 |
| 缺少行注释命令 | 宿主需要自行处理多行选区、前缀、撤销和快捷键 | 提供可卸载的行注释扩展，支持自定义前缀、反向选区和精确批量编辑 |
| 代码片段依赖文本发生变化才能启动 | 相同文本替换或空占位符可能无法启动；仅最终停靠点的完成状态依靠版本变化推断 | 复用已有文本进行占位符导航，显式区分插入失败和成功结束，保留历史与重做 |
| 片段正文和占位符映射脱节 | 字符过滤、CRLF 规范化或回调改写可能让占位符仍引用旧正文 | 同步规范化正文及偏移；插入前快照并验证模板，拒绝丢字符、代理对中点、非法重叠和循环依赖 |
| 镜像与嵌套字段跟踪不完整 | 相邻重复字符可能定位到错误副本；父字段覆盖后子字段仍可导航；子字段变化未同步祖先镜像 | 按实际编辑范围选择来源，清理被覆盖子字段；模拟子字段至祖先的传播，合并为一次精确批次和撤销步骤 |
| 延迟通知和重入事件使片段版本过期 | 同帧输入后立即 Tab 可能使用旧范围；递归通知可能先递送较新版本 | 内容事件携带前后精确范围及前版本；导航前刷新输入，校验版本链，保留上下区域独立编辑并结束不安全会话 |
| 缺少按词移动和删除 | 内置 `CodeKeymap` 将额外 Ctrl/Alt 回退到普通移动／删除 | 新增可选 `CodeWordEditingExtension`，支持 Ctrl/Option 键位、Shift 选区、Unicode 码点边界和单步删除撤销；默认键位保持不变 |
| 缺少大文件的位置映射索引 | `toOffset`、`lineAtOffset` 和 `columnAtOffset` 逐行扫描所有前置行；编辑后还要承担全量扫描成本 | 增加懒加载 Fenwick 行长前缀索引：首次查询后为 O(log lineCount)，同一行编辑增量更新，跨行结构编辑失效后按需重建；保留 UTF-16、换行边界和代理对行为 |
| 缺少保存状态 | 撤销／重做仍递增文档版本，单凭版本号无法判断内容是否回到保存点 | 提供 `isDirty()`、`markSaved()` 及异步快照重载；精确比较规范化内容，保存保留历史并终止连续输入合并 |
| 缺少行列跳转界面 | 只有宿主可调用的定位 API，越界坐标会被静默截断；无法直接通过键盘或触摸输入目标 | 新增可选 `CodeGoToLineDialog` 与作用域扩展，接入命令面板及 Ctrl/Command+G；严格校验 1-based 坐标，展开目标折叠并保护选区、历史及焦点生命周期 |
| 缺少格式化服务 | 宿主只能直接调用批量编辑，自行处理异步快照、过期结果、选区范围、过滤和撤销 | 增加可插拔的文档／选区格式化 provider、控制器和扩展命令；不可变快照、取消与版本守卫、精确批量编辑及单步撤销统一处理 |
| 过滤期间取消的工具仍可能提交 | 批量编辑只检查版本和只读／禁用状态，过滤器可以卸载扩展或取消异步任务后仍提交原结果 | 为精确批量编辑增加最终提交谓词；过滤只执行一遍，提交前再检查请求身份、生命周期、模式和版本 |
| 缺少开箱即用的格式化实现 | JSON 只有高亮和结构能力，格式化需要宿主另行接入 | 增加严格 JSON 格式化器，仅编辑 token 间空白，保留字符串转义、数字原文、键序和重复键；非法语法和过深嵌套整批拒绝 |
| 缺少诊断修复／代码动作服务 | 宿主需自行管理建议发现、预览、显式应用、过期结果及撤销 | 新增不可变代码动作模型、异步 provider、保留结果和整篇预览；显式选择后以精确批次提交，并提供按诊断 code 配置的替换规则和 Alt+Enter 扩展命令 |
| 文档版本不足以标识诊断批次 | 内容不变时新分析可覆盖诊断，旧修复仍使用相同文档版本 | 新增独立 `diagnosticRevision` 与诊断监听器；每次接受 set／clear 都推进修订，接收和提交前共同校验文档、诊断、光标、选区及请求身份 |

此前的行列跳转复用了定位、展开折叠和滚动能力，格式化服务进一步统一了快照、精确批量编辑与
作用域扩展生命周期。JSON provider 验证了语法检查、精细编辑和单步撤销的完整路径，默认同步运行，
大文档可由宿主 worker 执行并回到 GDX 线程提交。

本轮在此基础上增加诊断修复／代码动作：发现和预览保留建议，宿主选择后再显式提交；同时增加
独立诊断修订，避免同文档版本的新分析使旧修复继续有效。内置 provider 按 code 匹配规则并精确替换
诊断范围；选项列表和预览界面由宿主提供，跨文件修改和语言语义仍交给宿主解析器或语言服务。
跨行搜索会牵涉匹配模型、渲染片段、缓存失效和替换语义，本轮保留其现有逐行行为，留作独立改进。

过滤器自己修改文档的行为属于宿主回调；拒绝外层操作不会撤销回调自身产生的修改。
搜索范围仍沿用固定坐标语义，编辑后需要宿主重新设置。

## 本轮验证

- 核心测试共 45 个测试类、526 项，全部通过，无失败、错误或跳过。
- 本轮新增 79 项代码动作／诊断修订回归：控制器 29 项、模型与规则 provider 35 项、扩展 10 项、诊断修订 5 项；覆盖不可变快照、相关诊断筛选、同版本新批次失效、预览、显式应用、首选项歧义、迟到／重复响应、过滤与监听器重入、安装回滚及单步撤销。
- 此前新增 54 项格式化回归：控制器 28 项、JSON provider 14 项、扩展命令 7 项、提交守卫 5 项；覆盖快照与缩进、选区范围、迟到／重复响应、取消与卸载、输入过滤与监听器重入、延迟内容通知、Unicode、扫描中取消、严格 JSON 校验、token 保留及单步撤销。
- 新增 18 项行列跳转回归，覆盖空文档与末尾空行、严格坐标与 UTF-16 校验、嵌套折叠、换行与滚动、实时边界、Enter 与触摸按钮、焦点拒绝与恢复、回调重开／编辑／卸载、只读快捷键、重绑定和安装回滚。
- 保存状态回归覆盖规范化基线、末尾换行、撤销／重做保留、连续输入合并边界、哈希碰撞、Unicode 码元差异、异步快照、复合编辑及监听器重入。
- 验证覆盖捕获组展开、有状态过滤器、无变化替换、重做历史、折叠保留、回调改写文档、反向选区、空白行、Unicode 文本、命令面板恢复焦点，以及相同正文和空占位符的片段导航、补全成功状态和按词扩展的导航／删除／撤销。
- 位置映射回归覆盖行列边界、UTF-16 代理对、4096 行文档、随机编辑、插入／退格／前删／换行、自动与选区缩进，以及 undo/redo 重放；另覆盖 `CodeEditor.toPosition` 和 `setCursorOffset`。
- `:core:positionMappingBenchmark` 在 20,000 行、1,000 个偏移、3 轮下得到线性查询 174.92 ms、Fenwick 索引查询 0.86 ms；结果仅作同机信息性比较，不作为测试门槛。
- 79 项片段与内容事件聚焦测试覆盖 CRLF 和变量映射、输入过滤整批拒绝、嵌套及多行镜像、被覆盖子字段清理、实际副本编辑、祖先传播与单步撤销、非法重叠和依赖环、同帧导航、区域外编辑、延迟通知及重入版本链。
- 桌面端 `:lwjgl3:compileJava`、Android `:android:compileDebugJavaWithJavac` 编译通过。
- 本轮未进行桌面 GUI 或 Android 实机交互验证；相关平台输入问题仍列为后续验证项。

## 后续优先项

| 优先级 | 项目 | 依据及建议 |
| --- | --- | --- |
| 高 | 桌面与 Android 输入验证 | 当前自动测试覆盖模型和部分 Scene2D 事件；仍需验证中文输入法组合输入、软键盘、手柄拖动、缩放及不同密度下的实际交互 |
| 中 | 正则替换长行性能 | `expandReplacement` 为每个匹配重新创建 matcher，并复制匹配之前的文本以提取展开结果。建议按行复用扫描和捕获结果，并增加单行大量匹配的基准 |
| 中 | 跨行搜索 | 现有正则按行执行，不能跨换行匹配。若增加跨行模式，应明确增量缓存、全文件快照成本和零长度匹配语义 |
| 中 | 语言能力与重构精度 | 已有格式化与代码动作 provider、JSON 格式化及按诊断 code 的修复规则；其他语言的语义修复、导航与重命名仍需宿主解析器或语言服务，word navigation 不能区分同名变量的作用域 |
| 后续 | 块注释、矩形选区和多光标 | 本轮只提供行注释。块注释需要语言边界规则；矩形选区与多光标需要扩展单选区数据模型及批量光标变换，应单独设计 |

## 验证约定

- 内容修改应可撤销，并尽量作为一次命名操作通知宿主。
- 只读、禁用、密码模式及过滤器拒绝操作时，保留用户已有状态。
- 选区终点落在下一行第零列时，该行不属于整行编辑范围。
- 保留 UTF-16 代理对边界，区分逻辑文档行与自动换行后的显示行。
- 性能改进需要测量；仅凭复杂度分析不声称已经改善实际帧率。
